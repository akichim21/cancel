# SKILL.md フォーマット

## フロントマター（必須）

すべての SKILL.md はフロントマターで始めること。

```markdown
---
name: skill-name
description: このスキルの説明（いつ使うか、何をするか）
---
```

### フィールド

| フィールド | 必須 | 説明 |
|-----------|------|------|
| `name` | 必須 | スキル名（ディレクトリ名と一致させる） |
| `description` | 必須 | スキルの説明。いつ使うか、何をするかを1-2文で記述 |
| `globs` | 任意 | 対象ファイルパターン（自動トリガー用） |
| `allowed-tools` | 任意 | 許可するツール制約 |

## 本文の構造

フロントマターの後に Markdown 本文を記述する。

```markdown
---
name: skill-name
description: 説明
---

# スキルタイトル

概要（1-2行）

## ガイド / ドキュメント一覧

| ガイド | 内容 |
|--------|------|
| [xxx.md](./xxx.md) | いつ読むか・何が書いてあるか |
```
